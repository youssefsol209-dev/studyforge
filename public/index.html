Features

Built for serious studying

🔍

Highlight detection

Colour highlights in your DOCX or PDF are read automatically to identify correct answers — no manual work needed.

🃏

Anki-ready export

Downloads a .apkg file named after your document, ready to import into Anki, AnkiDroid, or AnkiMobile.

🔀

Shuffled every run

Choices are reshuffled each session so you test understanding, not just position memory.

🔒

Nothing stored on server

Files are processed in memory and deleted immediately. Your notes stay on your machine.

📊

Session scoring

Track correct vs wrong with a live score and pie chart. Retry only the questions you missed.

📤

Share your deck

Export any deck as a .json file and share it. Anyone can import it and study the same questions.
